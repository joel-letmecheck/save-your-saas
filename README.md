# Can Your SaaS Survive 1M Visitors?

An interactive game that teaches scalability concepts through real-world engineering decisions.

## About

This game simulates the challenge of scaling a SaaS application to handle 1 million visitors per day. Players make 7 critical engineering decisions under time pressure, balancing:

- 💰 **Budget** - Monthly infrastructure costs
- ⚡ **Capacity** - Requests per second (RPS)
- 🧑‍💻 **Technical Health** - Code quality and architecture

Each decision teaches a principle about performance, scalability, and engineering trade-offs.
