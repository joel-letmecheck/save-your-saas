# 🎮 Game Mode Switching Guide

The game now has **two question sets** that you can switch between using URL parameters.

## 🔧 Technical Mode (Engineers)
**URL:** `https://joel-letmecheck.github.io/save-your-saas/?mode=technical`

- Uses technical terminology (Redis, PostgreSQL, RPS, indexes)
- Detailed engineering concepts
- For developers and technical audiences
- Questions about query optimization, caching layers, connection pools

## 💼 Business Mode (Marketers/Non-Technical) ⭐ DEFAULT
**URL:** `https://joel-letmecheck.github.io/save-your-saas/` or `?mode=business`

- Plain language, no jargon
- Relatable business scenarios
- For marketers, PMs, executives, non-technical folks
- Questions about "slow pages", "hosting costs", "testing properly"
- Same game mechanics, just explained differently

---

## 🎯 How to Switch Modes

### At Your Booth:
1. **For marketers/non-technical:** Use the default URL (no parameter needed)
2. **For engineers:** Add `?mode=technical` to the URL

### Quick Links:
- **Business (Default):** https://joel-letmecheck.github.io/save-your-saas/
- **Technical:** https://joel-letmecheck.github.io/save-your-saas/?mode=technical

---

## 📊 A/B Testing Strategy

### Week 1: Test Business Mode
- Use default URL for all visitors
- Track: completion rate, leaderboard signups, booth engagement

### Week 2: Test Technical Mode  
- Share the `?mode=technical` URL
- Track: same metrics

### Compare:
- Which mode gets more completions?
- Which gets more leaderboard signups?

## 💡 Key Differences

| Aspect | Business Mode | Technical Mode |
|--------|---------------|----------------|
| **Language** | "Database", "hosting", "speed layer" | "PostgreSQL", "Redis", "RPS" |
| **Concepts** | "Organize data better" | "Optimize query + index" |
| **Audience** | Marketing, sales, executives | Engineers, DevOps, CTOs |
| **Tone** | "Your website might crash" | "System has no proven sustained capacity" |
| **Learning** | Business impact of tech decisions | Engineering principles & trade-offs |

---

## 🚀 Recommendation

**Start with Business Mode** (default) since:
1. Broader audience appeal
2. More accessible = more completions
3. Marketers get excited about understanding "how software works"
4. They can explain it to others (word of mouth)
5. Engineers will play regardless of difficulty

Switch to Technical Mode if you notice:
- Mostly engineers at your booth
- People saying "this is too simple"
- Technical conference/meetup audience
